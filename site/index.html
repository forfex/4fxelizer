4FXELIZER

Turn high-res textures into crunchy PSX-style low-res, palettized, dithered ones. Built for artists, runs on the GPU.

Download View on GitHub

Windows · macOS · Linux — free and open source

Features

A non-destructive stack of stages, like adjustment layers. Reorder them, stack them, switch them off, and watch the result update live.

Reorderable stage stack

Adjust, Downscale, Upscale, Quantize and Dither. Drag them in any order, add the same stage twice, click one to preview the image at that point.

Real dithering

Bayer, blue noise, halftone, lines, crosshatch, checker, N64 magic square or your own pattern image, plus Floyd–Steinberg, Atkinson, Stucki, Sierra and more, with serpentine and wrap-around scanning.

Masks & maps

Decide where the dither goes: edges, shadows, saturation, or your AO, cavity and curvature maps, loaded automatically from _ao / _orm files. Combine, invert and blur masks, and run a different pattern outside them.

Smart palettes

Generate up to 8192 colors in OKLab with median cut, Wu, octree or k-means, start from PICO-8, NES, Game Boy, CGA or C64, import .hex .gpl .pal .act .ase, edit and lock colors, or pick them from the image with the eyedropper.

Downscale & upscale filters

Box, Lanczos, dominant color, edge-preserving, contrast-aware; back up with the N64 3-point filter, Scale2x, sharp bilinear and more.

Presets

PSX 8bpp / 4bpp / 15-bit, N64, NES-ish, Game Boy, Crunchy. Save your own as shareable .4fxpreset files.

Exact export

PNG, TGA or BMP, full color or indexed, with palette order kept and transparency at index 0. No color-space surprises.

WebGPU speed

Every stage is a compute shader with per-stage caching, so tweaking a slider only re-runs what changed.

Your workspace

Dock, tab, float and resize the panels, switch between built-in workspaces or save your own. Undo covers the stack and palettes; split view, pixel grid and a 3×3 tiling view to check seams.

Gallery

Get started

  1. Download the installer for your OS from the latest release (Windows setup, macOS dmg, Linux AppImage or deb). Builds are not code-signed yet, so Windows SmartScreen or macOS Gatekeeper may warn.
  2. Drop a texture into the window (PNG, JPG, TGA and more), or use File › Open Image….
  3. Pick a preset or tweak the stack, compare with the split view, then Export a PNG, TGA or BMP, full color or indexed.

Requires a GPU with WebGPU support. Windows 11 is the verified platform so far; macOS and Linux builds are produced by CI and feedback is welcome.

Build from source:

git clone https://github.com/forfex/4fxelizer.git
cd 4fxelizer
npm install
npm run dev
